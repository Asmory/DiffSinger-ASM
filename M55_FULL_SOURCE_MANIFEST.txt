DiffSinger M55 full-source reconstruction
=========================================

This archive contains the complete source tree reconstructed from the retained
M40.1 full-source snapshot by applying the historical M41, M42, M43, M44, M45,
M46, M47, M48, M49, M50 and M55 patches in order.

Core project directories:
  src/       C + x86_64 assembly implementation
  include/   public/internal headers
  tools/     packers, validators and microbenchmarks
  tests/     tests
  scripts/   in-repository milestone scripts
  docs/      project/milestone documentation
  Makefile   build system

Additional archive-only directories:
  milestone_runners/  M51-M55 external benchmark/diagnostic runners retained
                      from the milestone bundles. These are kept outside the
                      core project layout to avoid changing the M55 build.
  reconstruction/     patch history and reconstruction/build logs.

Generated build outputs, Python bytecode caches, model weights, and virtual
environments are intentionally not included. This is a complete CODE archive,
not a model-weight archive.

Verification performed before packaging:
  make -j2 build/dsasm-vocoder-m40 build/dsasm-acoustic
  Result: PASS
  Native binaries linked only against libc/libm on the verification host.
